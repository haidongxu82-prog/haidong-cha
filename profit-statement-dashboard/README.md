# 利润表经营分析系统 / 老板利润经营驾驶舱

本项目是一个本地可运行的 MVP 单页应用，核心计算不依赖 AI。

## 启动

```bash
npm run dev
```

打开：

```text
http://127.0.0.1:5173/
```

也可以直接用本地静态服务打开 `index.html`。Excel 解析库和图标库已经放在 `src/vendor/`，运行时不依赖外部 CDN。

## 已实现

- Excel / CSV 上传与字段映射
- 页面手动编辑利润表
- 毛利、毛利率、总费用、净利润、净利率等核心指标计算
- 本月与上月环比分析
- 年度目标设置与偏差分析
- 自定义标杆设置与标杆差距分析
- 10 条默认经营规则
- 规则阈值修改、启用停用、恢复默认
- 自定义规则新增
- 红黄灯异常预警与固定经营建议
- 一页式月度利润复盘报告
- 报告复制、导出文本、打印
- AI 增值解读入口预留

## 计算边界

核心指标、预警等级、规则触发和报告中的系统判断均来自确定性公式与规则库。AI 区域仅预留接口，不参与原始数据计算，不修改系统分析结果。
