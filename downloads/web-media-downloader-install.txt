海东 AI 网页素材下载器 v1.4.0
================================

这是一个适用于 Chrome、Edge、Brave 等 Chromium 浏览器的本地网页素材下载插件。

主要功能
--------
- 扫描当前网页中的图片、背景图、懒加载图片和直链视频；
- 可逐项勾选后点击“下载手选”；
- 也可以使用“一键下载全部”；
- 下载文件保存在浏览器默认下载目录下的“电商素材”文件夹；
- 所有识别和下载都在用户电脑本地完成，不上传网页或素材。

安装方法
--------
1. 下载 ZIP 压缩包并完整解压，不要直接在压缩包内安装。
2. 打开浏览器扩展管理页：
   - Chrome：chrome://extensions
   - Edge：edge://extensions
   - Brave：brave://extensions
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压目录中的这个文件夹：
   ②【安装时请选择这个文件夹】海东AI网页素材下载器
6. 打开目标网页，点击浏览器工具栏中的插件图标即可扫描。

升级方法
--------
下载新版 ZIP，解压到新目录；在扩展管理页移除旧版，再重新加载新版目录。

能力边界
--------
本插件不绕过登录、会员、付费墙、访问控制或 DRM，不承诺下载 M3U8、DASH、Blob 等流媒体资源。
请仅下载和使用你有权使用的素材。
