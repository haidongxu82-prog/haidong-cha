Curriculum · 5 大板块

这一天，会带团队走过 5 大板块

01

换脑

用 AI 的正确认知

先换脑子，少走一年弯路。这一块决定后面所有技巧使不使得上劲。

02

内功

三条贯穿全课的心法

所有产出能稳定出好结果的底层功夫。

  • 遇事先问 AI，换一个本能反应起标题、定价、回差评、想活动，先问它一句再动手
  • 把 AI 当成「能力很强的实习生」来用它不熟你家业务，得给清晰指示，也得盯着
  • 看清 AI 的能力边界该信的信、该核的核，知道什么时候别依赖它
  • AI 不能「无中生有」想要像你家的，就得先喂它真实素材
  • 多学底层逻辑，以通百通抓住原理，比追着学一个个技巧省力得多
  • 一个字「拆」、两个字「多拆」先让它出一份「识别报告」，确认它真懂了再动手
  • 注意力有限：宁愿一步分十步一次只干一件事它才办得好，别十步并一步
  • 专业工具做专业事每个环节挑最强的，一个工具干两件事往往两头不讨好
03

会说

提示词与你的专属 AI 助手

把话跟 AI 说清楚，是一切产出的入口；再把好用法，固化成一个懂你的助手。

  • 提示词的润色 / 修改 / 一键转格式大白话丢进去，出来就是精简、专业的提示词
  • 从 0 到 1，打造你产品的专业生图提示词任意细分品类都能造，比如某款浴室拖鞋
  • 搭一个「入门级评估」智能体把需求发给它先出一份专业评估，附核心指令、粘贴即用
  • 现场演示：我用 AI 做的一整套电商工具箱Coze + Claude Code 做的，接 DeepSeek，成本几分钱
04

干活 · 图

电商最核心的图，一套套走通

每一套都是真实跑通、可现场演示、能直接复用的方法论。

  • 电商详情图整套生成1–10 张白底图 → 两步得提示词 → 逐张生成，一套跑通
  • 详情图提示词「调教」：重美观 → 重转化同一套流程，换个目标就换个风格
  • 洗图：换产品，还能还原原图的设计水平产品一致、摆放、背景、文案跟随，四点都顾到
  • 白底图 → 多姿势模特图衣服和原图尽量一致、不走形，保住细节
  • 用 AI 裂变买家秀（真实、无 AI 味）真背景 + 真模特 + 衣服交叉互换，一下裂变一批
  • 「AI 味」是怎么来的、怎么去掉原始素材本身真，出来的图就不假
  • 一句话生成专业信息图促销规则、参数对比，一张图看明白
05

干活 · 视频与文案

让画面动起来，让文案更能打

从一张图、或一条参考视频，做出你自己的产品视频；再把一线要写的文案一次配齐。

  • 图生视频：一张图直接生成产品视频有现成好图就别从零生，更稳、更接近成片
  • 复刻爆款视频、换成你的产品拆它的钩子和节奏，模仿运镜与拍摄背景
  • 电商文案生成一次最多 15 套、套套不同角度；小红书 / 抖音 / 淘宝 / 京东 / 通用
  • 标题 & 关键词优化多平台优化、命中关键词，可批量粘一列、导 Excel
  • 差评 / 中评回复多版得体公开回复，5 种语气可选，保住链接口碑
  • 直播 / 短视频脚本含黄金 3 秒开场 / 促单 / 拍摄提示，按时长控字数
  • 大促活动文案包选节日 + 填产品，slogan + 短信 + 朋友圈 + 公告一键出
