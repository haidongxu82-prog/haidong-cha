📝 使用说明

填一下商品和目标平台，一键生成多条平台优化标题 + 命中关键词，带字数校验和违禁词自查，可直接粘到后台。工具免费，只需你自己的 AI 接口 Key（几块钱就能开始）。

🔒 数据安全：你填的产品信息、你的 API Key、生成的文案，都从你自己的浏览器直接发给 AI 接口，不经过本站服务器，Key 只保存在你自己电脑里。不放心可按 F12 → Network 自行验证：生成请求只发去了 AI 接口，没发给本站。
（本站仅做基础访问流量统计，如页面访问量、来源，不含你填写的内容和 Key。）

第一步 · 准备一个 AI 接口 Key（二选一）

DeepSeek　推荐 · 最简单

国内接口，支付宝/微信充值，几块钱用很久。

  1. 打开 platform.deepseek.com 注册登录
  2. 「充值」充一点余额（几元起）
  3. 「API Keys」创建密钥，复制 sk- 开头的串

OpenRouter

想用 GPT / Claude / Gemini 等多模型。⚠️ 充值多需境外支付方式。

  1. 打开 openrouter.ai 注册登录并充值
  2. openrouter.ai/keys 创建 Key（sk-or- 开头）
  3. 到 models 复制模型 ID（如 deepseek/deepseek-chat）

第二步 · 把 Key 填进工具

用 DeepSeek：在「🔑 API 设置」把 sk- Key 粘进去 → 点「保存」→ 显示「已配置 ✓」即可（默认就是 DeepSeek，直接用）。

用 OpenRouter：点开「高级 · 换用别的 API 接口」→ 预设选 OpenRouter → 模型名填你复制的模型 ID → Key 粘到上面 → 点「保存」。

Key 保存后记在本浏览器，下次不用重填；换电脑或浏览器需重填。

第三步 · 生成标题

  1. 填产品名称（必填）；核心关键词、类目填了更精准
  2. 选目标平台（淘宝/京东/拼多多/抖音各有字数与规则），设标题数量（1–15 条）
  3. 点「✦ 生成标题」，等 15–30 秒
  4. 每条标注字数（超平台建议会标红）、命中关键词与优化点；可「复制标题」或「复制全部」，不满意点「换一条」

常见问题

会很贵吗？

很便宜，DeepSeek 一次生成通常几分钱，按用量扣。

提示「API Key 无效」？

检查 Key 有没有复制全、有没有多空格；用 OpenRouter 要确认 Key 和「接口预设」都选对。

提示「账户余额不足」？

去对应平台（DeepSeek / OpenRouter）充值即可。

提示「无法连接该接口」？

请用 DeepSeek 或 OpenRouter（已验证可用）；OpenAI 官方接口不支持浏览器直连，想用 GPT 请走 OpenRouter。

文案有点夸大 / 想更合规？

已内置广告法约束，但 AI 偶尔仍会冒夸张词，发布前请自行核对一遍，避免违禁用语。
